# 限制与未完成项

## 兼容性

- App 目标为 Apple Silicon Mac；当前包是 arm64 ad-hoc 测试签名，不是 Developer ID 签名，也不是 Apple 公证构建。
- ANE 路径依赖 macOS 私有的 Espresso/E5RT 接口，系统更新可能改变行为。
- 研究和实机验证不代表所有 M 系列芯片、macOS 版本、相机或显示器都兼容。
- 相机格式、权限、FPS、延迟和功耗必须在每台目标机器上验收。

## 数值与图像

- CPU reference、coefficient round-trip 和某个 H13 运行通过，不等于 H19 原机硬件数值已经取得。
- 模型输入是源视频归一化后的非线性 YUV 码值；HDR 物理观感、显示器 EDR 能力和不同片源仍需实机比较。
- 视频反向拖动、暂停参数重复性和 HDR 预览的交互体验仍应在目标 App 版本上复验。
- 没有把“处理后的画面更亮”当作模型效果结论；亮度差需要结合源片传递函数和显示元数据分别判断。

## 分发

- 仓库不附带模型权重或 `.llvnrkit`。
- 不能因为代码采用 Apache-2.0 就推断 Apple 固件、模型或 tuning 获得了再分发权。
- 使用者必须自行确认原料和生成资产包的使用范围。
